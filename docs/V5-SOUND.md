### Provisioning real music

1. Obtain artist-provided, rights-cleared, deliberately curated hook/chorus exports, ideally **8–15 seconds**, preferably compressed MP3 or AAC/M4A. Never rip Spotify, hide its iframe, use its SDK as a soundtrack or automatically cut full masters and call them curated.
2. Place the real exports inside `public/CEO19/audio/`. Re-run the inventory for actual paths/byte counts. It does not infer release, duration or permission from filenames.
3. Add one `RadioAudioAsset` per approved release: real `src`, `bytes`, verified `duration` (or null until runtime decode), `gain`, `startTrim`, explicit `rightsCleared` and `curated`. Also record the real file in the central public asset inventory, with `kind: audio` and `role: audio-preview`.
4. Listen to each outgoing join. Use `transition: {mode: 'cut', milliseconds: 0}` for unknown, silent or abrupt boundaries. Opt into `crossfade` only for reviewed musical boundaries, 300–800 ms. No join is crossfaded blindly. Gain must be reviewed against the other exports. The importer does not modify music files.
5. Test the actual exports on desktop and physical Safari/iPhone/Android, including interruption, network delay, volume, Cinema and route changes. The current tests use simulated buffers and cannot establish artistic quality, real loudness or device compatibility.

The transport rejects remote/unsupported sources, invalid gain/trim, streams over **8 MiB**, decoded exports over **30 seconds**, impossible trims and declared/decoded duration mismatches. The 30-second ceiling is a safety bound, not a target. A full master should be exported offline into an approved preview first. No credentials or new provider/library are needed for local playback.

## Persistent ownership and playback

`SoundProvider` is mounted in the shared locale layout. It owns one `AudioManager` across client routes within that locale; the entry, Home, Music, Archive, EPK and Shop do not own separate players. Full document reload resets the sound choice. The existing language switch crosses locale root layouts and performs a full document load, so it also resets sound; this routing convention is preserved. No completed/sound flags are persisted. Action-only components use a stable `useSoundManager()` hook; only settings subscribe to position updates, avoiding carousel/gallery rerenders on every radio clock tick.

The manager owns one lazy Web Audio context, a master gain, music bus and quiet SFX bus. `RadioTransport` is its internal mechanical transport, not a second app state manager. State includes `soundEnabled`, `muted`, `volume`, `isPlaying`, `currentTrack`, `currentTime`, `userPaused`, `isCinemaOpen`, `isExternalMediaActive`, `mediaLeaseActive`, `availability` and `radioStatus`.

Only an actual entry/speaker/resume/retry click may start music. `AudioContext.resume()` runs synchronously in that gesture, before asset requests, decode or animation callbacks; the prefixed Safari constructor is supported. Unlock has cancellation and a finite timeout. Ordinary input may unlock interface SFX after an interruption but never resumes music. Unsupported/denied audio never blocks entry. Silent mode creates no context, decoded buffers or playback sources.

With approved files, the first available track starts and the queue loops indefinitely. Only the current and next short exports are loaded/decoded; at most two scheduled music voices exist. Musical boundaries use the audio clock and native gain curves, not a JavaScript interval. A single sleeping 250 ms timer publishes UI progress only while running. Reviewed crossfades use equal-power curves; insufficient lead time uses a cut. The music bus reserves headroom at .64; the effects bus is .08 and allows at most three quiet procedural voices. Normalized exports and actual musical loudness must still be auditioned.

Pause retains the audible position, stops scheduled sources, aborts requests and cancels the UI timer. Explicit resume continues that position. On pause during a crossfade, the dominant voice is retained. Skip and intro completion stop only logo effects: radio playback continues into Home. One available export loops without repeated decoding. Failed files are skipped within a bounded queue; exhausting it shows an error with explicit Retry. Retry clears failed entries. Network timeout, late loading and decode failure never show a fictitious playing track. A late next export may cause honest buffering; the engine cannot guarantee gapless playback when the network cannot deliver the next file on time.

The compact navbar master disables all local sound. When enabled, RADIO opens optional nonmodal settings with actual now-playing, Pause/Resume/Retry as appropriate, volume, sound off and an honest missing-source message. Missing sources now also mark the RADIO trigger with `!` and a descriptive tooltip. The panel supports native Escape/light dismissal, keyboard controls and a non-Popover fallback. Controls remain touch-sized. Labels are EN/FR. The waveform animates only during real playback and respects reduced motion. The global switch does not pretend to control an external platform's audio.

In development only, one small read-only diagnostic panel reports Web Audio support, decoded-file readiness, playable track count, context state, current local source, actual transport state, volume/mute and the last safe error. Observing it never initializes audio. Its observer is cleaned up on unmount/Strict Mode reuse. Both its mount and render are guarded by `NODE_ENV === 'development'`; production has no panel or diagnostic timer. HTTP status, decode failure, invalid duration, unlock timeout and browser-denial names are retained without publishing arbitrary error messages or personal data. See [the actual V5.2 root-cause investigation](V5.2-AUDIO-DEBUG.md).

## Competing media, visibility and effects

- Watch Now pauses radio synchronously before Cinema mounts. Cinema and in-page music players hold reference-counted suppression leases: music and SFX cannot compete with the open player. Closing a player releases its hold **without restarting music**. Explicit radio Resume is required; it is disabled while an in-page media lease is still active.
- Outbound Spotify/YouTube/streaming links conservatively pause local sound. No external playback state is claimed. An explicit radio Resume or sound-enable gesture clears outbound intent; active in-page leases remain protected.
- Hidden tabs, page hide and interrupted/suspended contexts pause music and release sources. Returning to the tab does not restart it. Interface input can unlock SFX; only an explicit radio action resumes the song.
- Scene SFX listen only to accepted `ceo:scene-settled` transitions, not wheel events. Archive effects follow deliberate photo commands/boundaries, are throttled and never follow each drag pixel. Photo autoplay is silent. SFX are original short filtered noise textures, with no sampled copyrighted recordings.
- Off/mute stops music/effects and suspends the context. Request generations and unlock epochs reject stale callbacks. Cleanup closes/disconnects the graph and supports React Strict Mode reuse. No separate HTML audio player or Spotify library is introduced.

Web Audio timing references: [scheduled source starts](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start), [gain automation](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/setValueCurveAtTime), [equal-power crossfade principles](https://web.dev/articles/webaudio-intro).
