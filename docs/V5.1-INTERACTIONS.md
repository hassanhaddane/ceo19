# CEO1.9 V5.1 — Interactive controls

The existing scenes, routes, media transports and marketing actions retain ownership of their behavior. This system changes their presentation; it does not add sound, defer clicks or create another state manager.

## Five families

| Family | Primitive | Language | Applied surfaces |
|---|---|---|---|
| Cinematic entry | `AudioChoice` | CUTOUT + DEPTH | Freestanding condensed type, original blue waveform for sound and a curved aperture with inverted type for silence. Official HKZ leads; the CEO logo signs the composition. Labels and actual sound gesture remain explicit. |
| Music | `MusicAction`, `RevealAction` | INK + SHIFT | Play, Watch, Lyrics, Home streaming access, Genius link, FilmPlayer fallback, editorial resources/EPK request or genuine download. |
| Navigation | `NavigationAction`, `ActionButton` | CUTOUT + SHIFT | Main scenes, Menu trigger, menu links, languages, release selector, EPK index, return links, footer networks/contact. The existing moving header marker becomes a print notch. |
| Shop | `ShopAction`, compact `ActionLink` | INK + DEPTH | Shop menu/nav destination, early access, waitlist submit, confirmation/unsubscribe action. Cream/blue print stamp with clipped corners. |
| Utility | `UtilityButton`, `UtilityLink`, `UtilityGlyph` | CUTOUT | Close, Skip, Previous/Next, mute, motion/flash, copy email, persistent player, dismiss/return. Transport glyphs replace anonymous arrow circles. |

`ActionButton` always renders a native button. `ActionLink` renders a native anchor; opt into `client` for existing Next.js navigation. `MusicAction` and `ShopAction` choose the link form only when given `href`. Refs, action type, disabled state, accessible labels, download attributes and original handlers pass through. Internal Link prefetch remains disabled.

`ActionLabel` is the readable foreground. `ActionMark` is an original registration/cut mark; it replaces the repeated diagonal arrows. No duplicate text layer hides the real label. Utility glyphs have accessible labels on their enclosing controls.

## Shared motion and input

`src/components/interactive/motion.ts` owns the two-principle assignments, 110 ms press, 220 ms text shift, 320 ms mask reveal, 460 ms return and maximum 3.5 px pointer depth. CSS tokens are applied by the existing locale layout. There are no additional animation dependencies.

`MagneticSurface` is mounted once in the locale layout. One delegated, passive pointer handler updates only the current depth control. One event-driven RAF also positions the existing CEO leaf silhouette. It sleeps when settled. No click interception, pointer capture or event cancellation is added. Only inner graphics follow the pointer; hit areas remain stationary. Press feedback does not delay the original action or browser audio unlock.

The leaf geometry comes from the previous repository cursor. No second cursor is mounted. The native pointer is hidden only after the leaf has entered the top layer and been positioned. Inputs, selects, textareas, iframes, touch, keyboard navigation, blur, unsupported popovers and reduced motion retain the native pointer. All cursor/ink decorations ignore pointer events.

## Context exceptions

- Photographs, carousel sleeves and the SOON artwork remain large native media controls. They carry family/cursor identifiers and retain their existing drag, flash, parallax and typography owners; they are not wrapped in another moving button surface.
- Official logos keep their original image variants and contrast. The header brand has no ink overlay.
- The skip-to-content link retains its conventional immediate accessibility behavior.
- Third-party YouTube, Spotify and Genius player controls remain owned by their official embeds.
- Privacy prose keeps readable inline links. Consent checkboxes and form fields keep their existing independent validation and semantics.
- Missing EPK/audio/commerce/marketing integrations remain honestly represented; this task does not activate them.

## Accessibility / responsive rules

Control targets are at least 44 px in their practical width/height. Header language links move into the existing menu below 1000 px to preserve those targets. The menu already contains the language controls. Labels are present at rest, touch does not wait for a hover sequence, and disabled Shop actions keep their paper background so the text remains readable.

Focus uses CEO blue registration outlines; entry choices use a cream registration diamond and a clear mask state rather than a rectangular border. Native buttons retain Enter/Space; links retain Enter. Existing dialog focus traps, Escape behavior and focus restoration remain unchanged. The shared motion preference and `prefers-reduced-motion` disable spatial following, the custom pointer and animated transitions, while keeping visible focus and state feedback.
