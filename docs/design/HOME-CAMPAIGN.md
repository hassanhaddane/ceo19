# CEO 1.9 — portrait campaign

Home only: authentic supplied portrait, stacked CEO / 1.9, an asymmetric architectural opening, reflective stepped monolith, native-scroll PAS DE RÉSEAU passage and CEO-blue printed continuation. Home occupies approximately two viewport lengths; no pinning or scroll interception.

## Implementation

- `src/data/homeCampaign.ts`: authentic photo source, localized copy, supplied atmospheric phrases and Home motion controls.
- `src/components/editorial/HomeExperience.tsx`: semantic campaign composition and continuation.
- `src/components/home/home.css`: independently composed desktop/mobile layout.
- `src/components/home/HomeMotion.tsx`: reversible clip, crop and scale choreography; bounded desktop pointer depth.
- `src/lib/signalMotion.ts`: session-only shared visitor setting, initially derived from reduced-motion preference.
- Signal gains an architectural shape uniform. The existing UV vertices interpolate from a closed stepped slab to the original surface/sphere/lens. Coherent displacement samples the actual surface, so matching seam vertices have matching noise. Analytic slab normals and procedural studio reflections keep material highlights consistent. Existing section profiles remain available.
- Motion controls render inside the existing menu. Native Home anchors preserve predictable fragment navigation.
