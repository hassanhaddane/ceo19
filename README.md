# CEO1.9 — Official website V3

An in-place creative redesign of the existing Next.js website. Five public scenes: HOME, MUSIC, ARCHIVE, WORLD and CONNECT. English is primary; French uses the existing localized routes and dictionaries.

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
```

`/` redirects to `/en`. Artist pages: `/en`, `/fr`. Secondary professional pages: `/en/press`, `/fr/press`. `npm start` serves the production build. The project uses the existing npm lockfile, Next.js 16, React, TypeScript, Tailwind, GSAP and self-hosted Anton / DM Sans. Their licenses remain in `public/fonts`.

The V3 foundation keeps the existing player, source validation, native modal accessibility, release deep links, archive drag and keyboard navigation. Its active presentation replaces the earlier decorative material layers. Unused Three.js / React Three Fiber modules and dependencies were retired during the final audit. The spatial Archive uses a bounded 2.5D DOM perspective composition. LIGHT UP, six declarative release worlds, on-demand Genius lyrics and a persistent Cinema environment are implemented. WATCH opens the current release’s official YouTube player inside Cinema.

Content lives in `src/data/artist.ts`, `assets.ts`, `releases.ts`, `lyrics.ts`, `socials.ts` and `gallery.ts`. Complete lyrics remain on Genius; local `lyrics` text is empty. Four supplied Genius song IDs/URLs and artist-provided short fragments live in `lyrics.ts`. TIMALS and MACHI BATEL have a SOON panel. Existing supplied dates, destinations and biography remain; unknown dates, credits, durations, previews and press resources remain nullable. There is no EP announcement.

The approved primary images are `public/CEO19/Logo/LOGO CEO OFFICIEL Blanc.png` and `LOGO CEO OFFICIEL Noir.png`. White is used over dark/video surfaces; black is used over the cream Music/Archive header. These replaced the JPG at the user’s request during the audit. The secondary `LOGO CEO.jpg` appears only in the site footer. No logo is recreated as typography, and the supplied transparency is preserved. Public filenames, capitalization, spaces and apostrophes remain intact; `assetUrl()` encodes path segments at the presentation boundary.

`src/app/globals.css` owns the six CEO palette tokens and semantic aliases. CEO blue is `#3572A3`, sampled from the supplied STOP THE RIOTS visual reference. The reference is color evidence, not a CEO release cover. `src/components/v3.css` owns scene composition and responsive styles. `src/lib/motion.ts` owns the foundation motion settings; `src/lib/visualEffects.ts` owns entry, smoke and video presentation presets. The shared parallax scheduler combines pointer interpolation and scroll depth, reduces complexity on touch devices, and disables movement for reduced motion. Smoke and lighter animations run only on interaction; the background film loops while the tab is visible. There is no scroll pinning.

The full public inventory is in `docs/asset-inventory.json` and the typed `publicAssets` export in `src/data/assets.ts`. `docs/source-asset-inventory.json` preserves the previous inventory's source provenance. Original photography remains in `public/CEO19`; existing optimized artist photographs remain in `public/images`. Previously generated architecture and chrome assets are inventoried as legacy assets and never used by the current page.

See [the V3 handoff](docs/V3-FOUNDATION.md) for inspection findings, exact assets, changed files, commands, browser checks and remaining content gaps. Historical design notes describe earlier implementations. The final [creative and technical audit](docs/V3-AUDIT.md) supersedes their implementation status.

The confirmed canonical origin is `https://ceo19.ma`; `SITE_URL` may override it for an approved deployment. Development builds and preview deployments (`VERCEL_ENV=preview`) disable indexing. On other preview hosts, set that flag before building. Analytics remains the repository's local event interface; no new tracking service was added.

## Persistent film and LIGHT UP entry

`VisualExperience` lives in the locale layout around the existing application shell. Its single `GlobalVisualBackground` video stays mounted through scene and release changes. MUSIC hides it visually without seeking or reloading it. The other four scenes use translucent versions of their established surfaces. Hidden tabs pause the decoder; reduced motion removes the video source and displays the poster. Failed autoplay also retains the poster.

The original `public/CEO19/CEO VISUALS/CEO visuels .mp4` is 1920×1080 H.264, 24 fps, 20.08 seconds, 50,018,907 bytes, with AAC audio. `public/media/ceo-visuals-background.mp4` is a derived 1280×720 H.264 / yuv420p copy at 24 fps with fast-start metadata and **no audio stream** (CRF 25, slow preset). The 1600×900 poster is extracted from the original at 3 seconds. Both derived paths and the original remain in the typed manifest; original bytes are untouched.

The native entry dialog displays the supplied primary CEO1.9 and HKZ PROD images. LIGHT UP runs a 2.2-second original SVG lighter / Canvas smoke reveal; Enter and Space activate the same native button. SKIP INTRO and Escape enter Home immediately. A locale-independent `sessionStorage` marker (`ceo19:intro:v3`) prevents replay on return in the same tab/session; the menu offers Replay intro. Storage failures fall back to in-memory state. Reduced motion uses a short transition and never instantiates animated smoke.

`SmokeBurst` uses three cached 128px procedural noise sprites and a canvas capped at 960×640, with no WebGL dependency. It is idle between interactions, stops scheduling frames in hidden tabs, and appears briefly on deliberate Music release changes. Entry presentation is in `src/components/visuals/visuals.css`; the established typography and asset roles are unchanged.

## Scene navigation, Home and shared interactions

See [the scene interaction handoff](docs/V3-SCENES.md) for current files, browser checks and device-testing limits.

The artist page keeps the **document** as its scroll container. `SceneFlow` enhances CSS `scroll-snap-type: y mandatory` and `scroll-snap-stop: always`; each scene is at least `100svh`. Standard desktop and mobile viewports show five complete scenes. The secondary footer is inside CONNECT so it cannot become an accidental sixth stop. Short viewports, enlarged text and browser zoom can grow a scene beyond one viewport; native document scrolling then exposes its content before moving on. No fixed-height nested content scroller is required to reach the Music or contact controls.

Most wheel deltas stay native. A small accumulated-intent check advances one adjacent scene when Chromium snaps an intentional wheel back to its origin. The next-boundary guard drains only a burst's overshoot / momentum tail. A fresh gesture after 190ms of quiet can advance again; PageUp/PageDown and links bypass that burst state. Ctrl-wheel retains browser zoom. Touch vertical panning remains native. Links and PageUp/PageDown move keyboard focus to the settled destination; the skip link focuses the main landmark. Pointer, native paging and focus changes cancel abandoned programmatic destinations, preventing a stuck transition state. Explicit navigation waits for alignment before committing scene history; native scroll settling creates one history entry per scene. Scene, release and legacy film hashes restore through Back/Forward and locale changes.

`src/lib/sceneNavigation.ts` shares active/settled scene state, gesture ownership and hash resolution with navigation and the persistent film. `acquireSceneGesture()` reserves navigation only during an axis-resolved drag; callers release on up, cancel, lost capture, blur and unmount. Music consumes horizontal cover swipes/wheel and its local arrow keys. Archive has a curated 2.5D photographic volume with real z-depth, bounded camera motion, pointer capture, horizontal inertia and keyboard photo navigation. Vertical navigation returns immediately after release. Native viewport-fixed dialogs own background focus/scroll; setting them fixed explicitly avoids Chromium jumping the snapped document to Home on modal focus. A future scrolling lyrics panel can mark `data-scroll-owner`; panel scrolling gets priority until its content edge. Existing Cinema dialogs use the same modal boundary. Cinema and Genius lyrics use these modal/scroll boundaries; see the media architecture below.

GSAP enhances **presentation**, not scroll position: a Music mask, Archive depth movement, World aperture, Connect row reveals and Home lettering have distinct finite transitions of 580–800ms. `src/lib/visualEffects.ts` centralizes timing, gesture thresholds, background presets and parallax coefficients.

Home uses the real persistent film as its dominant visual, the official corner logo, localized positioning headline, precise artist/origin metadata and one scroll cue. The architectural passage is original SVG. `GlobalParallax` uses one event-driven animation-frame scheduler and DOM refs/styles for film, atmosphere, passage, lettering, details and photographs, at intensity .8 with a .28 mobile factor. Each layer has independent coefficients; photograph crop margins bound travel. There are no React updates per pointer event, and frames stop once interpolation settles or the tab is hidden.

The adaptive floating navigation uses the official logo, all five scene labels, EN/FR and one moving blue marker. Its full-screen native menu opens through an architectural aperture and closes in reverse, with focus containment and Escape. The menu exposes the **same** global film behind its blue/black negative space; it creates no second video. Replay intro still uses the existing session entry.

The compact original SVG leaf cursor supports DEFAULT, PLAY, VIEW, DRAG, ENTER and CLOSE. Movement adds bounded rotation/scale without particles. Its top-layer popover remains visible over native dialogs; inputs retain the native cursor. Coarse pointers and reduced motion retain native behavior. The menu offers a localized Full motion toggle: the system preference remains the default, and an explicit opt-in or reduction persists in localStorage (`ceo19:motion:v3`) across tabs, reopenings and language changes. Existing session choices migrate automatically. A visible MOTION / FX control shows the current state; the menu can restore the device setting. Switching to reduced motion releases the decoder and stops parallax, cursor and smoke; switching back enables the same persistent video element.

Browser-specific snap momentum still depends on the browser/OS. Validation uses Chromium mouse wheel, trackpad-style pixel delta streams and dispatched native touch events; physical trackpad inertia and iOS/Safari need device verification. Locale links preserve the active hash and session marker but perform a full document navigation, so background playback can restart across locale reloads. Scene/release navigation keeps one mounted decoder.

## Animation initialization diagnostics

In development, run `window.__CEO19_ANIMATIONS__.snapshot()` in Chrome DevTools. The event-driven snapshot reports hydration/fonts, motion preference, GSAP activity, active/settled scenes, pending scroll requests, parallax, the spatial DOM camera, persistent-video playback and runtime errors. It does not poll or update React on pointer frames. The global diagnostics API is absent in production. This checkout uses native document snap and DOM perspective, not ScrollTrigger, Lenis or WebGL; those systems are reported as unconfigured.

Scene entrances reconcile the current settled scene after intro completion, including direct hash loads, with generation-scoped async imports and GSAP context cleanup. Layout changes remeasure a pending native smooth-scroll destination; releasing internal gesture ownership resumes settling. Gallery capture-loss handling distinguishes the stage from bubbling child events during implicit touch-capture transfer. Header geometry is observed across font swaps and responsive changes. Background playback uses readiness/visibility/network/user-gesture events for recovery, invalidates stale promises on cleanup, and retains the same video element across scenes. No initialization delays or global animation resets are required.

`npm test` includes controlled playback lifecycle regressions: Strict Mode teardown, stale promise/pause events, interrupted startup, visibility, blocked autoplay, static motion and bounded network recovery.

When diagnosing a page with every effect absent, check the visible MOTION / FX state first. With the system's reduced-motion preference enabled and no explicit visitor override, a static poster and stopped effects are intentional. The visitor can enable full motion from the header; this choice persists for that origin, synchronizes other tabs, and can be reset to the device setting from the menu. Storage denial retains the in-memory/session fallback.
