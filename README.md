# CEO1.9 — Official Website V5

In-place update of the existing Next.js artist site. English is the default; French uses the existing localized routes. The public experience contains HOME, MUSIC and ARCHIVE with a compact social/contact footer. EPK / Media and the DROP LAB demonstration showroom have independent English/French routes. See [the V5 architecture and migration report](docs/V5-ARCHITECTURE.md).

```sh
pnpm dev
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run build
node scripts/audit-assets.mjs
```

The supplied workspace already uses pnpm 12, with `pnpm-lock.yaml` and `pnpm-workspace.yaml`. Both were present before this work and remain untouched. The tracked npm lockfile is also preserved. No dependency versions or framework configuration were changed. The installed Next.js is 16.4.0; `package.json` retains its existing ranges.

`/` redirects to `/en`. Artist routes are `/en` and `/fr`; professional routes are `/en/epk` and `/fr/epk`; Shop is `/en/shop` and `/fr/shop`. The former `/press` routes permanently redirect to EPK. The canonical origin remains `https://ceo19.ma`. Existing preview indexing rules, metadata and analytics are preserved.

00 INTRO now waits for ENTER WITH SOUND or ENTER WITHOUT SOUND, then transforms the official HKZ mark into the CEO1.9 logo. Every full public document load offers the choices again; there is no persisted completion flag. Internal scene/EPK/Shop navigation retains the current mode. Skip, Escape and menu replay remain available. Silent mode allocates no interface audio graph or local preview transport. A discreet speaker toggle and optional CEO RADIO settings control local music, volume and quiet procedural interface textures. One persistent Web Audio engine loops the approved playlist, preloading only the current and next excerpt, with reviewed 300–800 ms crossfades. Cinema and external music suppress local audio without automatic music resumption. No artist excerpts exist yet: all six typed radio entries are disabled, their sources/durations remain null, and the UI reports that music is unavailable. `node scripts/inventory-audio.mjs` lists real files without guessing ownership, duration or approval. See [sound ownership and missing-file instructions](docs/V5-SOUND.md).

SHOP is a separate blue printed navigation destination, visible in the mobile header. Clicking it opens the optional early-access dialog after route entry. Direct Shop arrival prompts once per tab visit unless dismissed; Close/Escape preserves DROP LAB and the selected concept, and the manual CTA remains available. Consent and actual server persistence are still mandatory for collection. See [Shop navigation and visit rules](docs/V5-SHOP.md).

The three public document scenes remain 01 HOME, 02 MUSIC and 03 ARCHIVE. Scene navigation derives from `src/data/artist.ts`. Release, film and photograph hashes retain their content destinations. Legacy `#connect` and `#network` bookmarks resolve to the compact footer; `#world` opens the locale EPK biography. Existing intro profiles, reduced-motion static handoff and economy rendering remain in use.

HOME uses the same persistent film on desktop and mobile. Desktop offers discreet music access; mobile provides the featured cover, direct Play/Watch actions, six compact release rows, streaming access. Professional links live in the menu/footer. Mobile Home scrolls normally through its content before handing back to three-scene snap. A long wheel burst stops with the last links readable; a fresh deliberate exit gesture settles on Music even when its delta is shorter than a viewport. Touch scrolling remains native.

MUSIC is one scene with six selectable release worlds. `src/data/releaseWorlds.ts` derives its media from the shared catalogue and records reproducible artwork palette samples. Six finite image-plane treatments, contextual artist-provided fragments and authentic TIMALS photography provide the environments. Tabs, previous/next, arrow keys and horizontal artwork swipes change the release without vertical navigation. Play Now opens the supplied Spotify release directly; Watch Now opens a lazy native YouTube player inside the release-specific cinema and stops competing music. The global MP4 stays mounted with its source and playhead preserved; it pauses while covered by Music or Archive. Home and the menu use the same persistent element without restarting it. Idle player chrome stays hidden in public scenes and the EPK/Shop routes; an engaged source remains available.

Lyrics initialize one of the four supplied official Genius embeds only when opened. TIMALS and MACHI BATEL show SOON. The panel owns its scrolling and always offers the real Genius URL when available. A source/song-validated message relays Escape from the sandboxed Genius frame. YouTube owns keyboard input while its player is focused; the visible Close control and the screen-reader hint provide the return path. No full lyrics are stored locally. Provider tracking cookies remain blocked by the opaque-origin Genius sandbox.

ARCHIVE is a bounded eight-photo space, using reviewed real photographs and orientation-correct uncropped derivatives. `src/data/archiveWorld.ts` records each image's native aspect, spatial position, depth, scale, contained crop and subject focal point. Depth controls pointer response, while drag, horizontal trackpad gestures, touch and arrow/Home/End keys move the camera. Vertical gestures remain available to document scene navigation. The fullscreen viewer opens with a short exposure/shutter transition; exposure-off sensitivity mode and reduced motion use a simple transition with no bright flash or shutter. Viewer navigation synchronizes the gallery and its return-focus target. Original source files are preserved. Four reviewed SHOW excerpts now crossfade behind Archive without black gaps. See [the exact photo and footage selections](docs/V5-ARCHIVE.md). The public global film pauses while this scene is active.

EPK / Media consolidates the former WORLD biography and `/press` content into a dedicated editorial dossier. It includes six releases with direct Spotify/YouTube links, three official video references illustrated by actual cover artwork, two selected photographs, the late-2025 launch milestone, prospective media/label/brand/live enquiries, HKZ production identity and professional contact with copy-email feedback. The detailed bilingual biography lives exclusively in `src/data/epk.ts`. Downloads are gated by `professional.pressImages` and `assets.epk`; no unapproved originals are exposed through EPK download controls. The historical inventory names a PDF, but the actual file is absent, so no performance figures or fake PDF download appear. See [EPK sources and publication configuration](docs/V5-EPK.md). The public footer reuses the four supplied CEO1.9 social destinations and secondary `LOGO CEO.jpg`. The original neighborhood map remains preserved in the asset inventory.

Shop now presents **CEO1.9 — DROP LAB**, four unmistakably non-purchasable design concepts: oversized hoodie, graphic T-shirt, sticker pack and keychain. Apparel uses dedicated generated front/back 2.5D atlases, explicitly labelled; stickers fan through three thin extruded shapes, while the matte polymer keychain has procedural solid geometry, a hole and connector/ring. The official supplied logo is layered onto prototypes without claiming an official product print. Front, Back, Rotate, keyboard/drag inspection, reset and previous/next work without navigation. The React Three Fiber/Three.js viewer loads only on Shop, bounds/adapts DPR, pauses behind dialogs/hidden pages and releases its renderer on route exit. Reduced motion removes idle float and entrances. WebGL failure preserves real 2D front/back previews and all catalogue navigation. There are no prices, stock, release dates or purchase actions. See [presentation and future-commerce boundaries](src/features/shop/presentation/README.md) and [asset provenance/prompts](public/media/drop-lab/ASSETS.md).

The optional Shop-only dialog retains the real email/SMS consent form. The selected Vercel/serverless architecture uses Neon Postgres over HTTPS, with a standalone migration, restricted application login and database-backed consent/rate limits. Actual Neon credentials and deployment still need setup; missing storage never produces fake success. Private SQLite remains available for local development and is rejected on serverless hosts. A minimal Shopify Storefront Web Components boundary prepares future commerce; no custom cart, order, payment or account backend is built. The browser-only product/variant/price/cart surface is prepared but inactive and unverified against a real store. Email confirmation can use configured Brevo; SMS verification/delivery still requires a provider. See [waitlist storage, privacy, private administration and deployment requirements](docs/V5-MARKETING.md). SHOP_MODE defaults to demo. Live is explicitly gated until actual Shopify data, showroom media and real-store tests are connected; setting an environment flag alone cannot activate purchases. An unconfigured Live request shows an unavailable store without demo merchandise. See [Shopify setup, ownership and integration status](docs/V5-SHOP.md).

The supplied `public/CEO19/SHOW/CEO DOCCCCC.mp4` is preserved: 409,256,910 bytes, 206.603333 seconds, 3840×2160 HEVC, stereo 48 kHz 24-bit PCM audio. Six visually sampled four-second excerpts start at 6, 40, 58, 93, 145 and 177 seconds. Browser exports in `public/media/world/` are 1280×720, 24 fps, fast-start H.264/yuv420p, approximately 1 MB each, with **no audio stream**. `src/data/worldClips.ts` records real files, posters, durations and source times. `ArchiveDocumentary` now uses two persistent slots and a fixed four-excerpt playlist, with only a brief dissolve overlapping playback. It holds the outgoing frame while a delayed next clip loads. Gallery/viewer pause and keyboard focus pause both footage and prints. Menu/scene exit releases sources, hidden tabs pause, and reduced-motion/data-saving devices use a static poster. The persistent global film remains mounted but paused behind ARCHIVE; one muted documentary decoder displays the current fragment, with a second active only for a short transition.

To prepare future excerpts, use `node scripts/prepare-world-clips.mjs inspect <source.mov> <inspection-folder>` and inspect the twelve technical samples. Then pass 4–8 reviewed ranges (JSON objects with `id`, `start`, `duration` of 3–6 seconds, and `selection: "reviewed"` or `"technical"`) to `node scripts/prepare-world-clips.mjs extract <source.mov> <ranges.json>`. `CEO_FFMPEG` and `CEO_FFPROBE` may name local executables. The tool refuses existing outputs/nonempty manifests, validates source bounds and verifies codec/no audio before publishing. Tooling was installed in a separate local cache; no application dependency changed.

`src/styles/tokens.css` owns the sampled blue/cream/black palette, type scale, spacing and foundation overlays. `src/lib/motion.ts` and `src/lib/visualEffects.ts` retain the shared timing, easing, parallax and decoder presentation settings. `src/components/v4.css` composes the new foundation; shared Music, Archive and Cinema styles remain in their existing files; EPK/Shop features import their own route styles.

`ArtistLogo` uses the exact official white/black PNGs. Header surface selects the correct variant. The secondary `LOGO CEO.jpg` is footer-only. Asset URLs preserve actual capitalization and encode spaces at the browser boundary.

The typed stable references remain in `src/data/assets.ts`. The complete recursive audit is `docs/V5-ASSETS.json`; it records exact paths, dimensions, transparency, byte counts, SHA-256 and video track timing. Original files remain untouched.
